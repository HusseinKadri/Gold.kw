# الملف المرجعي الشامل لمشروع كراج AUTO

مرجع ثابت لأي عمل يخص الهوية التجارية، الموقع، الخدمات، التصاميم، الفيديوهات، الإعلانات والتسويق.
يفصل بين المعلومات المؤكدة والتفاصيل التي تحتاج إلى استكمال، حتى لا تختلط الحقائق بالافتراضات.

---

## 1. الهوية التجارية

| البند | المعلومات المعتمدة |
|---|---|
| الاسم العربي | كراج AUTO |
| الاسم الإنجليزي | Kraj AUTO |
| النشاط | صيانة وإصلاح السيارات |
| الطابع | رسمي، احترافي وفخم |
| الألوان | كحلي، أحمر، ذهبي |
| لون AUTO في بعض التصاميم | الأحمر |
| الشعار | الحفاظ على الشعار الرئيسي |

### قواعد الهوية

- عدم إضافة كلمة «مركز» إلى الاسم.
- عدم تغيير الشعار الأساسي.
- عدم إضافة كلمات إنجليزية أخرى في التصاميم التي يُطلب فيها استخدام الشعار فقط.
- عدم إضافة نقاط أو زخارف أسفل حرف الجيم.
- اعتماد مظهر احترافي بعيد عن التصاميم التجارية الرخيصة.

| البيان | التفاصيل |
|---|---|
| المدينة | درعا – سوريا |
| المنطقة | المنطقة الصناعية |
| المعلم القريب | بجانب مديرية النقل |
| الإحداثيات | 32.6226416, 36.1215116 |
| رقم الهاتف | 098 363 7770 |

- سبق ظهور خطأ `country` عند إضافة النشاط إلى Google Business.

## 3. الخدمات المعتمدة

- ميكانيك السيارات.
- كهرباء السيارات.
- برمجة السيارات.
- تشخيص وفحص أعطال السيارات.

## 4. الواجهة واللافتة

- لافتة بواجهتين.
- الأبعاد المقترحة: 8 أمتار × 1.5 متر.
- طُرحت شعارات BMW وMercedes وPorsche وRange Rover ضمن التصور البصري.
- الحفاظ على وضوح اسم كراج AUTO وأن يكون العنصر الأساسي في الواجهة.

## 5. التخصص والعلامات التجارية

توجه تسويقي نحو السيارات الأوروبية، مع إبراز:

- Mercedes-Benz
- BMW
- Porsche
- Range Rover

العبارة التسويقية المستخدمة: «متخصصون بالسيارات الأوروبية».
هذا توجه في الهوية التسويقية، وليس إثباتًا بأن السيارات الأوروبية هي نطاق العمل الحصري.

## 6. الهوية البصرية بالتفصيل

| اللون | الرمز |
|---|---|
| أحمر فاخر | `#E10606` |
| ذهبي معدني | `#D4AF37` |
| كحلي داكن | `#0B1A3A` |
| أسود فاخر | `#0A0A0A` |

**الخطوط:** العربية Cairo Bold — الإنجليزية Montserrat Bold.

**نسخ الشعار:** الشعار الأساسي بالألوان — نسخة أحادية فضية/بيضاء — أيقونة مختصرة.

**التوجه البصري:**

- إضاءة سينمائية.
- خلفيات سوداء وكحلية.
- لمسات حمراء وذهبية.
- سيارات فخمة وبيئة ورشة احترافية.
- أجهزة تشخيص ومعدات حقيقية.
- تجنب المبالغة في المؤثرات والزخارف.

## 7. خدمات إضافية مقترحة (تحتاج تأكيدًا قبل الإعلان عنها)

- صيانة الفرامل.
- صيانة نظام التكييف.
- صيانة نظام التوجيه.
- برمجة الوحدات الإلكترونية ECU.

لا تُخلط هذه الخدمات مع الخدمات الأربع المعتمدة في القسم 3.

## 8. الفيديوهات والمحتوى الإعلاني

### فيديو افتتاح سينمائي (~15 ثانية)

| التوقيت | المشهد |
|---|---|
| 00–03 | أجواء الكراج والسيارة والإضاءة |
| 03–08 | مشاهد ميكانيك وكهرباء |
| 08–12 | برمجة السيارات والأنظمة الإلكترونية |
| 12–14 | تشخيص الأعطال وإظهار شعار كراج AUTO |
| 14–15 | الموقع ورقم الهاتف |

### خطة المحتوى المصوّر

- إعلان الافتتاح.
- صورة تعريف الخدمات.
- صورة الموقع.
- منشور العد التنازلي للافتتاح.

### أفكار المحتوى المعتمد توجهها

- تصوير العطل قبل الإصلاح وبعده.
- شرح الأعطال الشائعة.
- تصوير عمليات الفك والتركيب.
- عرض أجهزة الفحص والتشخيص.
- إبراز دقة العمل والنتيجة النهائية.
- فيديوهات واقعية من داخل الكراج.

## 9. التسويق والإعلانات

**Facebook وInstagram**

- بناء حضور تجاري للنشاط.
- إنتاج Reels احترافية.
- إنشاء محتوى يثبت جودة العمل.
- استهداف أصحاب السيارات في المنطقة الجغرافية المناسبة.
- إعداد حملات إعلانية عبر Ads Manager.

**Google Business**

- إضافة كراج AUTO على خرائط Google.
- معالجة خطأ `country`.
- تثبيت الموقع الصحيح.
- تحسين الظهور في نتائج البحث المحلية.

**Google Ads**

- طُرح الموضوع سابقًا.
- لم تُثبَّت حملة نهائية، ولم تُوثَّق ميزانية أو نتائج.
